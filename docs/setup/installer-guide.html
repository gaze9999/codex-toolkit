工具安裝與設定指引

依選定工具完成帳戶, 相依與實際操作驗證

先看本次結果

完成安裝或需要人工處理時, 此頁會在預設瀏覽器開啟. 套件安裝, MCP 註冊, 帳戶登入與實際呼叫是不同步驟, 請依輸出的缺項繼續處理

顯示狀態下一步
manual_setup_required先完成該工具要求的 app, 帳戶, notebook, project 或檔案範圍設定, 再執行同一入口
missing_dependencies依缺項補齊相容的 runtime 或套件, 不重裝已符合需求的項目
manual_verification_required檢查已完成, 接著確認帳戶權限, 工具載入與安全的實際操作
安裝失敗或平台不支援依原始錯誤與退出狀態處理, 核對平台及版本, 之後的安裝步驟不會自動補跑

需要額外設定時

  • OAuth 服務: 使用 Codex MCP 設定中的帳戶連接, 或該服務正式支援的 connector 流程. 需要命令列登入時使用 codex mcp login <實際 entry 名稱>
  • API key: 在自己的電腦依該工具要求設定環境變數, 不把值寫進 repository, 登入網址, 指令紀錄或對話. 各電腦的憑證分開建立
  • App 或本機服務: 先啟動必要 app / 服務, 再選定核准的 project, notebook, 資料庫或檔案範圍
  • Home Assistant: 先啟用官方整合並核准可提供的 entities, 再以 --server-url 指定不含憑證的 endpoint
  • RSS: 以 --feeds-path 指定實際存在的 OPML / JSON 檔案
  • PATH: 依安裝輸出與所用工具的說明確認執行檔位置, 需要時重開終端機. 安裝工具不會直接替你變更永久 PATH

確認可用

  1. 重新載入 MCP 或開啟新的 Codex 對話, 核對工具是否出現
  2. 使用公開資料或已核准範圍執行一次安全讀取, 核對帳戶權限與實際回應
  3. CLI 工具先核對版本及安全的操作結果. 瀏覽器工具另驗證指定頁面的互動與必要 console / network 證據

操作與語言

工具清單輸入 0 或按 Enter 返回類別, 類別清單輸入 0 顯示全部, Q 或 Enter 離開. 選擇「顯示目前用途的全部工具」可查看該用途下的全部項目, 每次仍只處理一項工具

選單預設為繁體中文台灣用語, 輸出編碼無法表示中文時使用英文. 輸入 L 開啟語言選項. 字型缺字或顯示異常時可手動選英文, 指引維持中文

launch-cli.cmd mcp --lang en
sh launch-cli.sh mcp --lang en
codex-mcp-setup --lang en

自動化使用 --yes 或 --no-guide 時不開啟指引, --list 與非互動輸入也不開啟. Windows 個別 PowerShell 入口可用 -NoGuide
