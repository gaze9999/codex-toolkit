# Data Visualization

Produce a visual that answers the reader's question, either independently or as part of a document. The document owner retains the narrative and governing sources; this Skill owns visual selection, data mapping, rendering and export checks.

Write titles, captions, analysis and delivery text as direct explanations of results, actions and necessary conditions. Remove boilerplate disclaimers, defensive wording, self-justification and unnecessary contrasts. Express material limits through their concrete impact and handling.

## Frame and select

Identify the question, audience, source, units, intended surface and useful interaction. Inspect supplied data or relationship evidence before choosing the form. Read [chart selection](references/chart-selection.md) for comparisons, trends, distributions, composition, relationships, flows or technical diagrams. Use a table when exact lookup is the task, and a direct sentence for a single fact.

Record the relevant source revision, filters, aggregation, denominator, missing-value handling and observation period beside the maintained figure source. Distinguish zero, missing and excluded values. Keep personal/company data within the authorized processing destination.

## Produce and integrate

Choose from the tools actually available in the current environment. Use an existing plotting runtime for reproducible scientific/exportable figures, supported diagram syntax for compact technical relationships, and an interactive renderer when filters, scenarios or drill-down materially help the reader. Read the selected tool's Skill or documentation when required. Keep tool-specific commands and schemas in that capability's maintained instructions.

Read [delivery and verification](references/delivery-and-verification.md) for construction, document integration and acceptance. Keep the editable source and necessary transformation with the output; the document references that maintained figure. Explain the result directly with a useful caption and nearby units/source. A standalone visual uses the same evidence and acceptance criteria.

Frontend diagrams and performance charts describe interaction, rendering/request behavior, state ownership and maintainability. Frontend work excludes Big O analysis and annotations. For substantial independent visualization work, use the task's existing delegation rules and assign ownership of the data transformation, figure source and outputs.

## Complete

Check mapped values and relationships against the source, inspect the actual rendered result at its target size, and exercise relevant interactive states. Report produced files, source scope, checks and any specific unresolved rendering or data issue. Retain one maintained figure source so a changed dataset, filter or decision can regenerate the affected outputs.
